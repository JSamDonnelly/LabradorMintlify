Remediation Help

### Missing button name

AI Generated

Original HTMLCaptured

```
<button class="icon-button">
  <svg aria-hidden="true">...</svg>
</button>
```

Recommendation

Add a visible text label or an accessible name such as`aria-label="Search"`so assistive technologies can identify the button purpose.

AI can make mistakes. Review recommendations before sharing them with developers.
