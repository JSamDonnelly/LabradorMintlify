Labrador can export your audit results in four formats. The right format depends on your audience, use interactive HTML for client presentations, a VPAT DOCX for formal procurement, and CSV or Jira CSV for developer handoffs and issue tracking. Every format is generated when you choose it from the **Export** menu in the project toolbar. CSV and DOCX files download straight away. The HTML report opens in a new browser tab, where you can read it, print it, or download it as a file.

## Available export formats

| Format | Best For | Plans |
| --- | --- | --- |
| Interactive HTML | Client presentations, stakeholder reports | All plans |
| VPAT / DOCX | Formal procurement, accessibility conformance reporting | All plans (VPAT projects only) |
| Standard CSV | Developer handoffs, raw data in Excel/Sheets | All plans |
| Jira-ready CSV | One-time import into Jira | All plans |
| Live Jira sync | Ongoing two-way sync with Jira Cloud | Core, Plus, Enterprise |

## How to export

<Steps>
  <Step title="Open your project">
    Navigate to the Projects dashboard and click the project you want to export results from.
  </Step>
  <Step title="Click the Export dropdown">
    In the project toolbar at the top of the project view, click the **Export** dropdown button.
  </Step>
  <Step title="Select your format">
    Choose a format from the menu. Every project shows:

    - **HTML**, an interactive web report
    - **CSV Export**, a flat spreadsheet of all logged issues
    - **Jira CSV Export**, issue titles and descriptions formatted for Jira's CSV import tool

    VPAT projects show three report options above the two CSV items:

    - **.docx**, a fully editable VPAT 2.5 DOCX file
    - **HTML** and **HTML (VPAT style)**, two HTML versions of the report
  </Step>
  <Step title="Get the file">
    **CSV Export**, **Jira CSV Export**, and **.docx** download to your device straight away. The HTML options open the report in a new browser tab. To keep a copy, select **Download HTML** at the top of the report, or **Print / Save PDF** to print it or save it as a PDF.
  </Step>
</Steps>

<Note>
  VPAT / DOCX export is only available for projects created with the **VPAT® 2.5 – WCAG 2.2** methodology. Standard WCAG 2.2 AA projects support HTML and CSV exports only. The project methodology is set at creation and cannot be changed afterwards.
</Note>
